# CLARA Orb label-clearance regression

The selected command label is rendered below its command action. On the upper arc, that visual direction points back toward the Orb. The command layout now derives a radial clearance multiplier from both command angle and label width so selected text stays outside the Orb protected circle across the ring rather than special-casing individual command IDs.

The browser regression checks the upper-right and upper-left problem sectors against the Orb's visible 117/320 radius.
