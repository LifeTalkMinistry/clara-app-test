# CLARA Support Badges

Upload the official supporter-tier badge image assets in this folder.

Recommended filenames:

- `supporter-tier-1.png`
- `builder-tier-2.png`
- `champion-tier-3.png`

Use transparent-background PNG files whenever possible.

These files are placed under `public/`, so the app can reference them directly with paths such as:

- `/support-badges/supporter-tier-1.png`
- `/support-badges/builder-tier-2.png`
- `/support-badges/champion-tier-3.png`

For the current Tier 1 image, upload it as `supporter-tier-1.png`.
