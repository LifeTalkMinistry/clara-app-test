# Ask Before You Spend deterministic intake contract

The production Buy Check intake is deterministic until the optional final alternative suggestion.

1. Capture exact item.
2. Confirm item with app Yes/No controls.
3. Ask whether the user wants to share a reason with app Yes/No controls.
4. Capture reason only when permission is Yes.
5. Capture price/payment structure.
6. Calculate Means impact locally from the authoritative financial engine.
7. Only when a reason was shared may the optional alternative AI helper run.

Binary control values are state transitions, not chat content. They must not be rendered as user chat messages.
