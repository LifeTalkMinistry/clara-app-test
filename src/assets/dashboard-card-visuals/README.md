# Dashboard Card Visuals

Upload the dashboard card illustration images in this folder.

Recommended files:

- `daily-tip-lightbulb.webp`
- `budget-wallet.webp`
- `budget-details-receipt.webp`
- `money-left-piggy.webp`

Preferred format:

- Transparent `.webp` or `.png`
- Optimized for mobile
- No solid background
- Soft 3D/glass fintech style
- Keep file sizes lightweight when possible

Usage plan:

These images will be imported into dashboard/card components and blended into CLARA cards with absolute positioning, opacity, and glass overlays.
